# Four-Model Comparison

`four_model_comparison.ipynb` consolidates the trained-model results for YOLOv8-S, YOLOv9-S, YOLO11-S, and YOLO26-S.

The comparison covers detection metrics and deployment-oriented properties such as model size and inference characteristics. YOLO11-S is used as the main model for the subsequent Jetson optimization stage.

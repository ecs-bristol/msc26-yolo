Repository upload guide
=======================

Commit to GitHub:
- Source code (.py)
- Training/comparison notebooks (.ipynb)
- Dataset YAML files
- README/documentation files
- Curated CSV result tables
- Selected result figures and final-system screenshots

Do not commit through normal Git:
- Full Kaggle train/val/test image dataset
- Raw Ultralytics runs folders
- Virtual environments
- Cache folders
- Large model weights and TensorRT engines
- Full benchmark videos
- Kaggle API tokens or local secrets

Recommended large-file handling:
- Keep model binaries locally unless the supervisor specifically requests them.
- If model binaries must be hosted in the repository, use Git LFS.
- TensorRT engine files should be regenerated on the target Jetson where possible.

Recommended result workflow:
1. Keep complete raw outputs locally.
2. Select the final summary CSV files.
3. Select the figures used in the report/discussion.
4. Copy only those curated files into results/.
5. Use descriptive filenames.
